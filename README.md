# PMS-VUE：工作項目管理系統

固定版面的個人工作台，用來集中整理公司與學校的工作項目，並在每個項目留下多筆備忘與工作紀錄。

## 需求背景與重點

這個系統的主要使用者是同時處理公司工作與學校作業的個人。需求來自使用者對自己 Notion 頁面的操作描述與畫面：目前每件事會建立一個 page，再把新需求、待辦、論文名稱、SQL、table 名稱及附件寫在同一頁。Notion 需要自行安排版面；內容累積後，重要的備忘容易混在頁面中，不易按次序找回。

- **固定版面、快速記錄**：不必先設計頁面或資料庫。開會或上課時，能用手機進入既有工作項目，直接開啟固定的備忘表單並記下內容。
- **明確分開公司與學校**：工作項目應有類別與所屬專案／課程，列表可依類別查看，避免兩種事情混在一起。
- **每筆備忘獨立保留**：備忘不能覆寫先前紀錄；建立後能依時間查看並搜尋。這是目前最重要的操作流程。
- **正式自用版必須跨裝置同步**：手機記錄後要能在電腦找回。僅有網站部署或瀏覽器暫存，不能滿足實際使用需求。
- **功能範圍**：每筆備忘可像 Ticket 一樣追蹤未完成／進行中／已完成；常用 SQL 與 table 名稱可先寫在備忘內容。圖片、文件照片與 PDF 上傳已取消。

本次需求訪談的對象是系統主要使用者本人，並參考其實際 Notion 頁面；目前尚未進行其他使用者的操作測試。

## 目前版本

W3 作業先以「在既有工作項目下快速新增一筆備忘錄，之後按時間查看」為核心流程，直接實作在 PMS-VUE，而非另做一份獨立 HTML。

主頁已有摘要、公司／學校分類篩選、搜尋、工作項目列表、快速新增、項目詳情與明暗模式切換。840px 以上以 Nuxt UI UTable 顯示列表；839px 以下逐張卡片完整顯示資訊，只需垂直捲動。項目列表可直接開啟備忘表單；每次新增會保留為獨立紀錄，依時間顯示並可在該項目內搜尋。總覽搜尋也會比對備忘主題與內容；點開搜尋結果後，詳情會帶入關鍵字並捲至匹配的備忘。明暗偏好會保存在瀏覽器。

W6 行動端調整提高了卡片正文與操作文字的字級和淺色模式對比，將主要任務的點擊區提高至至少 48×48 CSS px，並讓頁首在放大時換行。這些是本專案的課堂練習規格，並不代表已完成整站無障礙稽核。

W7 為每筆備忘加入獨立 Ticket 狀態，主頁表格及行動卡片依工作項目即時顯示未完成、進行中、已完成數量。可在詳情中新增備忘並變更狀態；這些變動仍只保留於目前頁面記憶體。

這是**靜態前端示範**：預設資料位於 `app/pages/index.vue`，新增項目、備忘、Ticket 狀態與工作紀錄只保留在目前頁面的記憶體中；重新整理即重設。尚未連接資料庫、提供登入或跨裝置同步。使用者已確認 GitHub 推送後 Cloudflare 會自動部署；部署更新的是網站程式，不會使頁面中的新增資料持久保存。

### 範圍限制

## 啟動

需 Node.js 22 以上與 pnpm。

```powershell
pnpm install
pnpm dev
```

開啟 http://127.0.0.1:3000。

## 檢查

```powershell
pnpm typecheck
pnpm lint
pnpm build
```

介面設計、RWD 與互動驗收見 [DESIGN.md](./DESIGN.md)；前後端開發規則見 [AGANTS.md](./AGANTS.md)。
